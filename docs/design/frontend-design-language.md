# Ongrid 前端设计语言与开发规范

本规范用于新增页面、调整布局和维护公共组件，记录仓库已采用的设计约定。以克制、清晰、适合持续运维的控制台为目标；未写明的页面结构先参考现有多数页面，不另创一套视觉风格。历史页面仍有不一致处，不能把这些差异当作新规范。

## 开发入口与维护边界

- 页面骨架复用 [PageHeader](../../web/src/components/ui/PageHeader.tsx)、[Card](../../web/src/components/ui/Card.tsx)、[EmptyState / EmptyStateCard](../../web/src/components/ui/EmptyState.tsx) 和 [PaginationFooter](../../web/src/components/ui/PaginationFooter.tsx)。参考 [设备](../../web/src/pages/Edges.tsx)、[日志](../../web/src/pages/Logs.tsx)、[监控](../../web/src/pages/Monitor.tsx) 的对应区域。
- 控件统一复用 [components/ui](../../web/src/components/ui/) 中的 **shadcn/ui 风格与派生组件实现**。复杂交互由 **Base UI** 支撑，原生输入继续保留浏览器验证和事件；统一适配本项目 Tailwind 3、主题变量和组件 API。新增控件先复用已有实现，缺失时在公共层按同一体系补齐，不在业务页面另写一套，也不直接复制另一套主题或升级框架。
- 公共外观和状态维护在 [styles/index.css](../../web/src/styles/index.css) 的 `.og-*` 规则中；Tailwind 映射和字体见 [tailwind.config.ts](../../web/tailwind.config.ts)。页面 `className` 补充布局、宽度、图标让位和代码字体，避免重复覆盖边框、背景、圆角、字号与聚焦样式。
- 本文是设计约定的集中维护入口。公共组件契约或视觉规则改变时，在同一个 PR 更新本文与相关测试；引用 shadcn 派生代码时保留 [MIT 许可](../../web/src/components/ui/shadcn.LICENSE)。

## 页面与布局

1. 列表页使用统一页头：标题、简短说明、右侧操作；筛选可放在 `PageHeader.extra` 或页头下方。操作组同一行用 `items-center`，需要时换行。小于 640px 时，`PageHeader` 的标题/说明与操作组上下排列，避免按钮把长说明挤成窄列；桌面仍左右排列。
2. 数据列表按信息用途选择表格或分行列表。一组相关信息优先用一个 `Card` 加 `divide-y`，不为每行重复套卡片；信息层级通过间距、文字与分隔表达。
3. 横向信息卡片左侧放标题、描述和元数据，右侧操作组与信息块垂直居中。窄屏允许操作组换到下一行，正文容器使用 `min-w-0`，避免按钮挤压正文。
4. 保留密集表格的横向滚动，不要把整个页面撑出视口；长字段可截断并提供查看完整内容的入口。下拉选项可换行，不能只显示无法区分的前缀。
5. 表单弹窗用 `Modal` 的 `sm` / `md` / `lg` / `xl` 预设；宽度受视口约束，长内容在正文区滚动，标题与底部操作保持可达。不要额外叠加互相冲突的 `max-w-*`。确实需要用户调宽时用现有 `resizable`。
6. 资源清单可将筛选栏与表格放在同一 `Card`，表格复用 `.og-resource-table` 的表头、行距与悬停样式。列表与配置详情随内容区宽度伸展，页头与正文保持对齐，不以固定最大宽度造成宽屏两侧大面积留白；阅读宽度限制仅用于长文本或表单。已保存目标按列展示；行内配置清单的新增入口可保留在列表底部，独立资源列表的创建入口放在页头，首次空数据时按下文提供卡片内入口。发现结果选择使用 `Radio` 配合 `.og-choice-row`，整行 `label` 可点击，选中和禁用状态保持一致；已配置范围明确标注，不能只显示一个不可点击的单选框。
7. 采集配置详情的表格使用 `.og-resource-table[data-variant="quiet"]`：表头与正文共用卡片底色，仅保留淡化的行间分隔；卡片标题和底部新增入口通过间距区分，不重复添加横线。
8. 小于 768px 的窗口默认使用已有的侧栏图标导航，允许展开完整菜单，切换页面后收起；不覆盖用户在桌面保存的展开/折叠偏好。
9. 首页是开始对话的工作区，允许使用阅读宽度限制，不套用资源清单的全宽规则。欢迎语居中，状态、输入框和建议卡片作为整体在可用区域垂直居中略偏上；短屏按内容自然滚动，不裁掉顶部。调整导航、会话列表或其他页面时，不顺带改变首页和对话正文的字号、对齐、宽度、间距。

### 模型配置页的局部 Liquid Glass

模型配置列表页、模型属性页和资源数据页的正文可使用 `.cmdb-liquid` 作用域的玻璃面板、背景光斑和蓝紫渐变主操作，参考[模型属性参考稿](./cmdb/model_attribute_management_apple_liquid_glass.html)与[资源数据参考稿](./cmdb/cmdb_instance_data_apple_liquid_glass.html)。模型配置列表页和详情页共用 `ModelConfigShell` 的**工作区顶栏**，不使用通用 `PageHeader`：顶栏横跨左侧模型树与右侧正文，左侧是 CMDB 标识（蓝紫方格 logo + “CMDB 资源管理平台”）、分隔线和面包屑，右侧是统计胶囊与操作组；面包屑最后一项就是页面标题（`h1`），列表页为“模型配置”，详情页为模型别名。统计胶囊合成一组、内部用细分隔线；操作组空间不足时整组换到下一行（宽屏靠右、手机靠左）；手机宽度隐藏品牌名，只保留 logo 和面包屑。列表页右侧依次是总数、已启用、已停用、含继承四个计数，以及刷新、内建模型和新建模型；详情页右侧是模型/标识/展示/属性/分组胶囊，以及刷新、模型定义和编辑模型。模型详情的页签栏（属性 / 表单分组 / 模型关系 / 唯一约束 / 触发器 / 自动发现）同样固定在工作区顶栏下方，只有页签内容在下方独立滚动，切换页签或滚动表格都不需要回到顶部。页签下方的整块内容区由页面提供同一层 `.cmdb-liquid` 工作区表面（渐变 + 光斑），属性页的玻璃面板和其他页签的卡片都直接铺在这块表面上，不再让属性页自己画一块带外边距的渐变面板：切换页签时背景不跳变，和模型列表的玻璃工作区保持一致。左侧模型树从顶栏下方开始，列表页和详情页都只保留搜索、分组树和管理分组入口，不再重复顶栏的新建按钮；详情页仍高亮当前模型。

模型列表的工具栏用三段带计数的状态筛选（全部模型 / 已启用 / 已停用），搜索按名称或别名过滤当前列表；“按分组显示”是可选的内存显示模式，搜索、按分组显示、列设置、刷新和列表/网格图标同排（列设置只在列表视图出现）；低于 1440px 时筛选与控件分两行，避免在两条左侧导航之间挤成多行。工具栏是工作区色带而不是浮动卡片：紧贴顶栏下沿、与模型树右边相接，横向铺满正文，表格滚动时保持不动。正文是一张满高的玻璃工作台卡片，表格直接从卡片顶部开始，不再有“模型列表 + 数量 + 列”的卡片头行：表头在卡片内吸顶，行在卡片自己的滚动区里滚动，分页条嵌在卡片底部（不再作为下面的独立浮层）；分组视图展示全部匹配行、不分页，卡片底部只保留行内容。平铺视图每页 20 条，分页条左侧显示“显示 x 至 y 条，共 n 条模型”，右侧为上一页、页码和下一页；分组视图避免把同一组拆到两页后组计数失真。分组表格保持一个 `DataTable`、一个列选择器和一个横向滚动容器，用跨列分组标题行区分组；网格分组使用扁平分节标题条，不嵌套 `.cmdb-liquid-group`，避免多层 `backdrop-filter`。表格行和网格卡片的编辑、启停、删除使用图标按钮（铅笔 / 电源 / 垃圾桶），保留 `aria-label` 和 `title`，颜色沿用蓝 / 中性 / 红；窄屏表格仍收进“更多操作”菜单。未分组模型进入末尾“其他”；分组接口只提供模型 id，页面必须与最新模型快照 join，并按接口顺序首组优先去重。

模型属性页按“生效数据类型”展示属性，而不是直接把存储代码当标签：密码、链接、文件和引用由属性标志解析，未索引文本显示为长文本，布尔显示为独立类型。列表的数据类型列和网格卡片共用同一套类型图标与名称；顶部类型筛选采用可多选的 OR 过滤，主行优先显示已使用类型（最多 5 个），全部 13 个类型及计数可从“更多类型”弹层选择，选中态使用浅色描边而不是实心主按钮，避免把 13 个类型读成一排主操作。页头把属性计数、必填/继承统计、搜索、列表/网格、策略筛选和分组操作收进同一块紧凑面板；属性表格使用更低的表头和行高，配置策略保持可点击胶囊。网格卡片同时保留必填标识、唯一标记、配置策略、属性标志和编辑/解绑操作，不能为了紧凑删掉可操作项。

模型关系页的“新增关系”使用纵向表单：源 CI 类型、目标 CI 类型、关联类型、关系约束、属性关联。前四项使用带占位符的下拉；关系约束显示“一对多 / 一对一 / 多对多”，不显示存储代码。属性关联默认给出一行“源属性 → 目标属性”，行尾提供删除和新增按钮（只剩一行时删除禁用）；候选属性按对端已选属性、值类型和关系约束过滤：排除密码、JSON、布尔、引用及未索引文本，两端的值类型必须一致，一对多禁止目标侧多值、一对一禁止两侧多值、多对多在对端为多值时禁止多值。切换源/目标类型只清空对应一侧，切换关系约束清空全部映射；半填的映射行就地提示并阻止提交。关系表在源/目标列显示模型图标、别名和模型标识，关系类型保留颜色点，关系约束使用标签；新增“属性关联”列显示前两组“源属性 → 目标属性”（属性已删除时退化为组数，无映射显示“—”）；源/目标列按内容宽度排列，属性关联列吸收剩余宽度，避免宽屏下两端被拉开；行操作使用带 `aria-label`/`title` 的图标按钮。

资源数据页复用模型配置的工作区结构：`WorkspaceBar` 顶栏横跨左侧模型导航和右侧正文，左侧是产品标识和“资源模型 › 资源数据 › 模型别名”面包屑，右侧是实例总数、本页、本页 Active/PROD/SLA 胶囊以及刷新、批量导入和新建实例；模型导航从顶栏下方开始，只保留搜索、分组树和高级查询入口，宽度与模型配置的模型树一致（lg 16rem / xl 18rem）。筛选工具栏作为工作区色带固定在顶栏下沿、与模型导航右边相接，环境/等级筛选、服务端搜索、“字段”入口和列表/网格切换都在其中，不随内容滚动。正文是一张满高的玻璃工作台卡片：表格在卡片内吸顶并滚动，分页条嵌在卡片底部；网格视图使用同一张卡片。左侧模型导航按模型分组（`c_ci_type_groups`）展示，分组标题带折叠箭头、文件夹图标、名称和模型数量，组内按模型 order/名称排序，未分组模型进入末尾“其他”分组；分组标题可点击折叠/展开并暴露 `aria-expanded`，折叠后保留标题，当前模型所在分组在切换或深链进入时自动展开；搜索只保留有匹配项的分组；分组读取失败时保持平铺并在导航内给出可重试提示，不阻塞模型切换；工具栏提供“字段”入口，打开“<模型> · 属性说明”对话框：属性表按名称、别名、类型、可检索、默认展示、唯一、枚举、多值、可排序、计算属性展示模型的全部属性，支持按名称/别名搜索；首列勾选决定列表与卡片显示的列，标识列固定并带锁标记，保存后立即更新表头与卡片；窄屏下表格只在对话框内横向滚动；关键词输入框是服务端全模型搜索：回车把 `_type:<模型>,*关键词*` 提交到 `/ci/s`（匹配后端已索引的属性值，可跨分页），清除或对空值回车恢复普通列表；环境/等级筛选仍只作用于当前已加载页，搜索生效时统计行显示“匹配实例”；工作台卡片只有一个纵向滚动容器（列表视图是表格自身的滚动区，网格视图是卡片正文），分页条固定在卡片底部。原来的整块玻璃 Hero 和四张 KPI 卡不再使用，避免与页头、工具栏重复。工作区顶栏在空间不足时把统计胶囊和操作整组换到下一行，避免把面包屑压成竖排；手机宽度隐藏品牌名，只保留 logo、面包屑和模型胶囊。

引用属性按被引用实例的名称显示，不逐格请求：页面按目标模型批量解析 `_id`，名称优先取该模型的 `show_name`，再回退 `unique_key`、`name`/`alias`；查找失败或被引用实例不存在时保留原始 id。原始 id 放在单元格 `title` 中供核对。
新建或编辑实例时，引用字段使用可搜索下拉而不是裸 id 输入：打开时加载前 20 项，输入时经 250ms 防抖调用 `/ci/s`；单值选择保存目标实例 id，多值引用支持连续多选与清除。
枚举属性的展示使用属性 `choice_value` 中的标签（如 `prod` → 生产、`critical` → 关键、`active` → 使用中），原始代码保留在 `title` 中；环境/等级筛选按钮也显示标签，但筛选和搜索仍按原始值执行。

资源数据的行/卡片操作使用图标按钮（详情、拓扑、编辑、删除），每个按钮保留 `aria-label` 和 `title`，不靠可见文字；拓扑图标直接打开抽屉的拓扑 Tab。资源详情是右侧 Drawer（字段可就地编辑，其余为只读视图）：头部左侧是模型图标（圆角方形容器），右侧第一行为资源名称、模型标签和状态胶囊；第二行为审计信息，依次显示 ID、更新时间（`YYYY-MM-DD HH:mm:ss`）、更新人和唯一标识（如 UUID，与名称不同时），缺失的更新时间或更新人不占位；右上角为关闭按钮。视图切换使用共享的下划线 Tab（详情、拓扑、变更历史、触发记录），每个 Tab 前带对应图标，不使用胶囊底；窄屏压缩图标与文字间距，保证四个 Tab 全部可见。Tab 栏使用带顶部内边距的不透明 sticky 容器覆盖抽屉正文的上内边距，正文滚动时内容不得从 Tab 栏上方露出。详情属性区使用与关联关系一致的卡片头部（图标、标题“属性”、属性数量和刷新操作），下面按模型表单分组用两列字段网格展示属性，密码只显示占位符；详情字段可就地编辑（对齐 cantor）：每个可编辑字段行尾提供铅笔图标按钮，悬停或聚焦时显示、触屏设备常显，点击后在该行内按值类型呈现控件（引用用可搜索选择、单选枚举用配置标签下拉、布尔用开关、日期时间用原生输入、JSON 用文本域、多值逐项增删）；文本与 JSON 在失焦或回车时自动保存，布尔、单选枚举和引用在选择后立即保存，多值在离开字段时保存，Esc 放弃草稿，不提供保存/取消按钮；每次只提交这一个属性；保存失败保留草稿并在行内显示后端信息，行内提示自动保存的触发方式。密码、计算属性和文件字段不提供行内编辑，仍走完整表单或专门页面。编辑保存后抽屉头部、状态和当前值同步更新，背后的列表静默刷新；跨模型切换后仍可行内编辑，整表单编辑仍只对页面原模型开放；底部关联关系区按模型关系图列出上游/下游类型和数量，侧栏可按类型过滤。关联表压缩为“资源、关键属性、操作”三列，关键属性优先显示环境/状态等字段并解析枚举与引用名称；每行提供详情、拓扑和在资源数据中打开的图标操作（`?type=<模型>&ci=<实例>` 直接打开该实例），分组标题提供“添加”入口，打开可搜索的目标实例对话框，选择后按上/下游方向写入关系并刷新。窄屏把关键属性收进资源行内，避免三列表格被挤压。关系删除仍不放在这个以查看为主的区域。拓扑使用 cantor 风格的实例关系图：思维导图/紧凑布局、关系标签与颜色开关、节点详情卡、叶节点向外逐层展开；内向关系只连边，不复制节点。双击节点把抽屉切换到该资源并保持拓扑 Tab（与 cantor 一致）；节点详情卡同时提供“切换到此资源”按钮，保证键盘和触屏可达。切换是对抽屉主体的只读跳转：同模型复用已加载的字段元数据，跨模型按目标模型加载属性与分组，并隐藏只属于原页面的编辑入口。历史与触发记录保留分页、空态、失败重试和用户回退为 `#uid`。抽屉的编辑入口回到原实例表单，不把编辑态混进历史/拓扑视图。监控和 Prometheus 告警没有对应后端资源映射，不放进抽屉冒充可用视图。

该视觉不改变公共 `Card`、`Chip`、`Button`、主题变量或其他页面；不引入参考稿中的 CDN、图标库或全局 Tailwind 配置。其他页面如需同类效果，先在本规范登记并复核深浅主题、对比度和滚动边界。

### 主导航与会话栏

- 主导航展开宽度为 232px，收窄时沿用图标导航；独立会话栏宽度为 272px，位于主导航右侧，只在首页和会话详情显示。两栏用途不同，不要求同宽。
- 会话栏沿用页面底色；桌面标题区高 65px，下方使用紧凑、透明背景的“新建会话”入口。顶部搜索与显示/隐藏按钮均沿用主导航的紧凑规格：15px 图标、`Button size="sm"`，同组按钮的留白和颜色一致。
- 显示/隐藏始终使用会话栏顶部同一个 `PanelLeftClose` 图标按钮。隐藏后完全释放会话栏宽度；鼠标移到主导航顶部品牌区域时临时弹出，浮层不挤动聊天区，移开后延迟收起。点击同一个按钮固定，再点隐藏；主导航不新增展开按钮，也不使用中间伸缩箭头或额外图钉。
- 隐藏/固定偏好在当前浏览器持久化，默认展开；悬停预览是临时状态，不保存。搜索、菜单与编辑期间保持可操作，支持键盘唤出、Escape 关闭和合理的焦点返回。悬停不是唯一访问方式。
- 会话列表独立滚动，滚动条细且低强调，悬停和键盘聚焦时可辨认。标题默认单行自然裁切，不用省略号或渐隐遮罩；仅溢出的标题在悬停/键盘聚焦时缓慢往返滚动，移开复位；尊重减少动态效果设置，并提供完整文字的可访问方式。
- 会话行文字为 14px、常规字重，默认 `zinc-400`，选中态适当提高对比；不展示时间，保留助理标记及重命名、删除菜单。列表搜索不能改变会话标识或当前草稿。
- 小于 1024px 时会话栏放在正文上方，通过已有移动端入口展开；切换会话后收起，不覆盖桌面偏好。加载失败保留已有列表并提供重试，编辑失败保留当前输入。

### 表格操作列

- 操作列表头与按钮组统一左对齐，按内容收紧；自动布局使用 `w-px` 配合 `whitespace-nowrap`，不为预估的按钮数量写死 320/340px 宽度。按钮过多时收进公共下拉菜单，不扩大操作列挤压信息列。
- 内容和操作数量会变化的表格优先自动列布局。保留 `table-fixed` 时，`colgroup` 必须覆盖每个实际列，宽度总和不得挤占新增列；不能给固定布局追加 `w-px` 操作列后假定它会按按钮内容扩展。长字段换行或截断，操作不能溢出单元格，横向滚动应能完整到达首尾列。
- 带固定操作列的表格使用 `.og-action-table`，固定单元格保留 `sticky right-0` 与层级。普通行和固定列共用不透明底色，表头也保持一致；不能用透明固定列透出下面的文字，也不能独立选一个更亮的底色。宽度不足 1536px（Tailwind `2xl` 以下）时操作列改为静态并留在行尾，避免固定列遮住数据列；宽度足够时仍固定在右侧；表格始终只在自身容器横向滚动。
- 验证深浅主题、默认与悬停状态、横向滚动、中英文、不同权限与按钮数量。新增选中态时必须同步整行与固定单元格底色。

### IPAM 地址空间页

- 页面沿用标准骨架：`PageHeader`、地址空间树卡片与内容卡片；不使用模型配置页的 Liquid Glass。桌面为“树 + 内容”两栏，小于 1024px 上下堆叠；树的节点列表最高 45vh（桌面 70vh）并在自身容器滚动，避免手机上把地址工作区推到首屏之外。
- 树显示“全部”根、分组/网段图标、主机计数和按节点的“新建分组 / 新建网段 / 编辑或重命名 / 移动 / 删除”菜单；计数由 CIDR 算术得出，不枚举主机。长名称截断并在悬停时给出完整名称；节点菜单的点击不得同时选中节点。搜索过滤时展开匹配项的祖先，使匹配结果可见。
- 五个页签固定为总览、地址分配、IP 搜索、子网列表、历史，状态写入 `?tab=&node=`；树加载完成后把已删除的深链节点回落到 `all`。窄屏页签允许换行，不横向裁切文字。
- 总览四张比率卡使用小圆环和数值图例，宽屏四列、窄屏两列；子网表按叶子子网显示名称/CIDR/主机数/在线率/已分配/空闲/扫描，操作图标带可访问名称。最近扫描为默认隐藏列，可从“列”中打开。为让操作列和名称列在 1280px 内容宽度下完整可见，主机数与扫描列在 1400px 以下自动隐藏、已分配列在 900px 以下自动隐藏，窗口变宽后恢复；这些列不在当时的“列”菜单中，避免提供无法生效的开关。
- 分页条位于表格/网格内容之后，不使用 `sticky` 悬浮覆盖行；长表滚动到内容底部即可翻页。`PaginationFooter` 默认右对齐显示范围与上一页/下一页；需要左对齐范围摘要和页码时传 `summary` 与 `showPageNumbers`，模型配置列表使用该形态。
- 地址分配页展示整个范围：未登记主机的行以“未使用”出现，已登记行覆盖状态、用途、使用对象、MAC 和描述。统计条为总地址数、已分配/使用、闲置/可用、分配使用率；状态胶囊的计数基于未过滤集合，派生状态为“已分配&在线 / 未分配&在线 / 已分配&离线 / 未使用”。筛选或切换网段后选择集自动收敛到可见行。
- 表格与网格共用选择状态：普通点击打开编辑，Ctrl/Cmd 增减选择，Shift 扩展区间；表格的复选框按可见页扩展。网格以最后一个八位组为标签、按派生状态着色并附语义色图例，颜色在深浅主题下保持白字对比。
- 地址编辑使用 `Modal`：状态、使用对象（模型声明为 choice 时用下拉，否则文本）、用途、描述、MAC、网关、子网掩码。单行预填，批量留空表示不修改；状态混合时必须明确选择；“回收”是状态 1 的动作，不提供删除。提交失败保留输入并在对话框内显示后端信息。
- IP 搜索使用 `/ci/s` 的服务端类型过滤与模糊匹配，行内解析所属网段；子网列表使用同一搜索接口。两者都提供状态/搜索、列显隐、导出和分页，行操作使用图标按钮。
- 历史分为操作日志与扫描日志：操作日志显示时间、操作人（管理员解析显示名，否则 `#uid`）、类型、CIDR 与描述；扫描日志显示 IP 数、开始/结束、耗时、结果和“查看”，输出与地址列表在 Popover 中展示。CIDR 搜索输入按 `*term*` 发送。
- 导出使用共享菜单，提供 CSV/Excel/JSON/YAML/文本，导出当前筛选后的行；使用已有 `exceljs`/`js-yaml` 依赖，不新增运行时包。
- 写操作按 `usePermissions().canMutate` 门禁；失败状态使用表格的 `error`/`onRetry` 并保留已加载数据，不能把请求失败画成空态或零值。
- 宽度不足 1536px 时表格操作列改为静态位于行尾，避免固定列遮住数据列；表格仍在自身容器横向滚动，页面不得出现横向溢出。390/768/1280/1920、中英文、深浅主题均需实看截图。

### 数据中心页

页面沿用标准骨架和 IPAM 的两栏结构：`PageHeader`、左侧存放位置树卡片、右侧工作区；桌面 18rem + 内容，小于 1024px 上下堆叠。选中机房写入 `?node=`，删除或深链失效后回落到未选择状态。树按区域 → 数据中心 → 机房显示，机房的机柜数向上累加；搜索保留匹配项的祖先并展开，长名称截断且悬停给出完整名称。区域的节点菜单建数据中心，数据中心的菜单建机房，区域和数据中心自身只用于分组，不改变右侧选中机房。

选中机房后，工作区依次是统计条、筛选工具栏、机柜网格或表格。统计条显示机柜数、设备数和容量使用率；使用率用圆环加“已用/空闲 U 数”，不只给一个百分比。机柜网格按 220px 最小宽度自动填充（手机 1 列、768px 约 2 列、1280px 约 4 列），不使用固定像素卡片；卡片使用 cantor 的机柜插画，顶部是名称标签和高度，异常时机柜上方显示橙色标记，底部是“已用/总 U 数”和使用率轨道。筛选无结果时显示“没有匹配的机柜”和“清除全部筛选”，不能显示成机房没有机柜。机柜表格显示名称、使用率，再显示订阅字段；`u_count`、`free_u_count`、`u_start`、`u_slot_abnormal` 不在表格重复成列，因为名称、使用率和异常胶囊已经表达。订阅字段在 1400px 以下只保留第一列、1536px 以下保留前两列，宽屏恢复；操作列和 IPAM 一样在 1536px 以下改为静态行尾，表格只在自身容器滚动。

机柜详情使用右侧 `Drawer`（最大 64rem，手机占满视口），页脚放编辑、删除和上架；查看者只保留关闭，不显示任何写入口。抽屉四个页签固定为“机柜视图 / 属性 / 设备列表 / 操作日志”：

- 机柜视图并排绘制前视图和后视图（手机上下堆叠），每个 U 位 24px，前视图 U 号在左、后视图在右，按 `u_numbering_direction` 从上到下或从下到上排列；机柜使用 cantor 的金属边框、穿孔顶条、正面指示灯和侧边锁扣图，设备按模型使用对应的前/后面板图（未知模型回退服务器图），按高度逐 U 重复。空 U 位是上架入口；点击设备块可用键盘聚焦并显示移动、迁移、下架按钮。桌面支持把设备拖到目标行；拖动和移动弹窗都走同一个 `to_u_start`。迁移弹窗只列当前机房的其它机柜，与 cantor 一致。
- 同一 U 位被多台设备占用时合并为一个红色异常块，点击打开冲突列表；没有权限时只读展示异常，不显示“调整位置”。设备超出机柜高度同样标红，并在视图上方列出未绘制的设备。
- 属性页按模型的属性分组展示只读字段；引用解析名称、枚举显示标签、密码只显示占位。
- 设备列表按设备模型分组，列为设备、起始 U、高度和该模型的订阅字段，支持导出当前类型。
- 操作日志按机柜分页，显示时间、操作人、上架/下架/移动、设备类型和设备名；操作人由管理员映射显示名，失败时回退 `#uid`，并支持按操作类型筛选和导出当前页。

新建/编辑节点使用模型自己的属性动态生成表单，不再硬编码 `name`/`code`：必填校验按绑定属性执行，布尔用开关、枚举用下拉、引用用可搜索选择、日期时间用原生输入。新建机柜必须能在表单里填写 `u_count` 和 `free_u_count`，否则创建出的机柜无法上架。编辑机柜修改高度时由服务端校验在柜设备是否仍放得下，失败保留输入并在对话框内显示原因。

写操作按 `usePermissions().canMutate` 门禁；读失败用可重试的错误面板，不能画成“没有机柜”。导出沿用共享菜单，导出当前筛选/所选机柜、当前设备类型或当前操作日志页。390/768/1280/1440/1920、中英文、深浅主题均需实看截图，页面不得出现横向溢出。

## 配色、文字与图标

| 用途 | 约定 |
| --- | --- |
| 页面、表面、分隔 | 中性 zinc 骨架；公共控件使用 `bg-bg` / `bg-card` / `border-border` 等语义类 |
| 正文、次要文字、辅助信息 | `text-text` / `text-text-muted` / `text-text-faint`，按信息层级使用，不能靠降低透明度隐藏必要说明 |
| 主要操作 | `Button variant="primary"`，使用 indigo |
| 品牌 | `--accent` 用于 logo 等品牌位置，不铺成大面积操作区 |
| 成功、降级、异常、信息 | emerald / amber / red / sky；状态优先通过 `Chip` 的 `tone` 表达 |
| 正常状态 | 小圆点加灰字，状态点用 `-500`，不为每个 OK 铺彩色背景 |

字号按用途选择，不把整个页面统一放大或缩小：

| 用途 | 字号 |
| --- | --- |
| 列表页标题 | `PageHeader`，16px / semibold |
| 页头说明、密集表格正文与常规控件文字 | 12px |
| 表头、次要元数据 | 通常 11px，关键说明不可压小 |
| 空状态标题 / 说明 | 14px / 12px，使用公共组件 |
| 会话列表标题 | 14px / 常规字重 |
| 首页欢迎语、对话正文 | 沿用对应组件专用层级，不套用表格的 12px |

- 沿用 Inter / 系统无衬线字体；ID、查询语句、命令等使用 `font-mono`。页头沿用 `PageHeader` 的层级，表单和密集控件沿用公共组件字号，避免各页微调形成多套尺寸。
- `text-[10px]` 等紧凑字只适合非关键元数据，不用于主要操作和必须读懂的表单提示。必填、错误和危险操作说明不能只靠颜色区分。
- 通用图标使用 `lucide-react`；通知渠道、模型等品牌图标复用现有 [icons](../../web/src/components/icons/) 组件，例如 `CommunicationProviderIcon`，不以相似的通用图标代替。
- 输入框内图标用 `top-1/2 -translate-y-1/2` 居中，装饰图标加 `pointer-events-none` 和 `aria-hidden`。独立图标按钮提供可访问名称。
- 不使用发光阴影、`hover:scale`、`animate-pulse` 或花哨的“刷新中”徽章；动效服务于交互反馈，不抢占业务信息。

### 明暗主题

语义变量由 `html.dark` / `html.light` 切换；新公共样式优先使用现有变量，不在页面写死一套深色值。旧页面 zinc 类依赖 CSS 的 light 覆盖，带透明度的变体必须确认存在对应覆盖，不能认为 `.bg-zinc-900` 会覆盖 `.bg-zinc-900/20`。

检查默认、悬停、聚焦、禁用、选中和错误状态在两种主题下的可读性。深色弹窗内的弱提示已有统一对比度规则；不要在局部重新叠加透明度使说明变淡。浮层通过 Portal 渲染，也必须检查主题与内容对比度。

## 控件选择与尺寸

| 场景 | 使用方式 |
| --- | --- |
| 页头、筛选栏、普通表单操作 | 默认控件高度 36px；`Button` 默认尺寸 |
| 密集行内操作 | `Button size="sm"`，28px |
| 常规独立图标操作 | `Button size="icon"`，36px；侧栏顶部紧凑操作沿用上述 15px 图标与 `sm` 按钮 |
| 文本、数字、日期、文件输入 | `Input`，保留原生 `type`、`required`、`min` 等属性 |
| 多行输入 | `Textarea`；组合搜索栏、聊天输入使用 `variant="inset"`，边框由外层提供 |
| 列表搜索 | `Input type="search"`，透明表面融入页面，保留边框和聚焦反馈 |
| 单选列表 | `Select`；通过 `options` 或已有 `<option>` 子元素提供选项 |
| 可复用已有值，也允许输入新值 | `Autocomplete`；例如环境、服务命名空间，使用 Base UI 交互及公共输入框和浮层样式，避免原生 `datalist` 的主题差异 |
| 复选、开关、互斥选择、范围 | `Checkbox` / `Switch` / `Radio` / `Slider` |
| 元数据与状态 | `Chip`（亦导出为 `Badge`） |

不要用独立的 `h-*`、`py-*` 和字号覆盖制造第三套常规控件尺寸。

上表用于新增控件选型。维护已有页面时，先检查并复用同一行、同一区域内同类元素的展示方式；不要因增加查看、复制等交互而单独更换一个字段的视觉容器。保留同组元素的字号、颜色、边框、间距与对齐，同时保留键盘操作和焦点提示。

### 时间范围

监控类页面复用 [TimeRangePicker](../../web/src/components/ui/TimeRangePicker.tsx)：快捷范围与自定义起止时间放在同一个弹出面板，避免切换自定义时在筛选栏新增输入行。快捷范围一键应用；自定义在本地时区编辑，点击“应用”才更新查询，取消或 Escape 丢弃草稿。触发按钮显示已选范围，完整日期可通过悬浮提示查看。日期输入复用原生 `datetime-local`，校验起止顺序、页面最小跨度及 7 天上限。关联跳转携带的固定时间窗保持固定。

### 按钮

- `primary`：当前区域的主要提交或创建操作。
- `outline`：次要操作；旧 `ghost` 保持相同的带边框语义。
- `subtle`：低强调操作；`link`：文本链接样式的按钮。
- `danger` / `dangerGhost`：删除等危险操作，分别为实心与低强调。
- `plain`：已有的语义色或动态选中态需要由页面提供时使用；页面必须同时保证背景、文字与悬停色搭配。

`Button` 默认 `type="button"`。提交表单必须显式写 `type="submit"`，不要依赖原生按钮的隐式提交行为。

### 标签与筛选栏

创建、编辑和工具执行参数用上方标签，`Label htmlFor` 对应字段 `id`；同一组字段保持一致。横向筛选用 `FilterField`，标签与控件共用外框，宽度设在外层；字段仍需要明确的可访问名称。

```tsx
import { FilterField, Input, Label, Select } from '@/components/ui';

// 横向列表筛选；role、setRole 和 roleOptions 来自页面状态。
<FilterField label={tr('角色', 'Role')} className="w-56">
  <Select label={tr('角色', 'Role')} value={role}
    onValueChange={setRole} options={roleOptions} />
</FilterField>

// 普通表单；name、setName 来自页面状态。
<div>
  <Label htmlFor="device-name">{tr('设备名称', 'Device name')}</Label>
  <Input id="device-name" required value={name}
    onChange={(event) => setName(event.target.value)} />
</div>
```

`Select` 默认按内容宽度排列，表单需要撑满列时加 `className="w-full"`。`onValueChange` 返回字符串，数字字段在调用方转换。选项超过 10 个时默认启用搜索，也可显式设置 `searchable`；聊天模型等低强调入口使用 `variant="ghost"`。不要给隐藏输入派发 `change` 模拟用户选择，测试应实际打开菜单并选择选项。

## 弹层、导航与交互

- 菜单、提示、轻量编辑、标签页分别复用 `DropdownMenu`、`Hint`、`Popover`、`Tabs`；不在页面重写定位、视口翻转、Escape 或焦点管理。
- 常规表单用 `Modal`；需要组合结构时用 `Dialog`。确认、提示和输入请求复用 [useDialogs](../../web/src/components/ui/useDialogs.tsx)，渲染返回的 `dialog` 并 `await` 结果；取消与卸载不能批准动作。异步等待后继续使用连接或选中对象时，检查它是否仍有效。
- 提交中禁用重复动作，失败保留用户输入并展示错误。加载、空数据、筛选无结果和请求失败要区分，空态按下文选择 `EmptyStateCard` 或 `EmptyState`；错误给出可执行的重试或修正入口，不能把请求失败显示成“没有数据”。
- 导航用链接，动作使用按钮。可点击卡片必须有键盘可达的入口，不能只在 `div` 上写 `onClick`；不要移除唯一的焦点提示。
- 无可见标签的字段使用 `aria-label`；错误字段用 `aria-invalid` 和 `aria-describedby` 关联说明。Tooltip 补充解释，不能替代必要的可见操作名。
- 所有用户文案走 `tr('中文', 'English')`，包含占位符、空态、错误、Tooltip 和可访问名称。避免同一字符串中英并排，检查较长英文是否挤压布局。

## 空状态与操作入口

### 容器与排版

- 独立列表或查询结果为空时使用 `EmptyStateCard`：统一圆角、细实线边框、中性卡片背景、居中的图标/标题/说明/操作。不要各页手写虚线框、纯文本占位或单独调整高度。
- 已有 `Card`、带边框的表格或详情面板内部使用 `EmptyState`，复用已有容器，不嵌套第二层卡片。图表暂无点位、下拉无选项等局部状态保留局部提示，不扩大成页面级空卡片。
- 优先传对应领域的 lucide 图标；缺省时 `EmptyStateCard` 使用 `Inbox`。图标 28px、标题 14px、说明 12px，文字按主题保持可读。最小高度由公共组件维护，长文案、英文、操作按钮允许自然增高和换行，不能截断必要说明。
- `EmptyStateCard.className` 设置外层卡片布局（例如外边距），不要传居中排版或高度来重建内部样式；`EmptyState.className` 会替换内部容器类，紧凑场景使用时必须保留可读排版。
- 保持页头、筛选和卡片的水平边距对齐。公共组件统一外观，页面负责状态判断、权限和业务动作，不在组件中推断“没有数据”的原因。

### 何时显示按钮

一致性指同类状态采用同一规则，不要求所有空卡片都出现按钮。每张卡片最多一个主要动作，确有不同用途时可附低强调次要动作。

| 状态 | 文案与操作 |
| --- | --- |
| 首次无数据，用户有创建/接入权限 | 显示一个明确主按钮，如“新建工作流”“接入 MCP”“新建助理”“添加仓库”；复用页头同一个处理函数、权限判断和表单。页头已有入口不意味着卡片内省略入口。 |
| 筛选无结果 | 说明没有匹配项；存在用户可清除的筛选时提供“清除筛选”，回到默认范围并重置分页。不能清除权限、租户或必须保留的资源范围；本来就没有可清条件时不放无效按钮。 |
| 日志、告警、技能等由系统/设备产生的数据 | 解释产生数据的条件；有明确且用户可访问的下一步时显示“配置采集”“查看接入说明”或“扩大时间范围”等实际动作，不虚构“创建日志/告警”按钮。清除筛选仍受上一条约束。 |
| 无创建/配置权限 | 保留状态说明，提示联系管理员；不渲染不可用的创建按钮，也不能只靠按钮隐藏代替服务端鉴权。可用的只读入口可保留。 |
| 加载中 / 请求失败 | 使用加载或错误状态；失败提供重试并保留已加载数据，不进入首次空数据引导。 |
| 等待选择资源、等待运行任务 | 说明前置条件；有明确选择或执行入口时引导到该入口，不显示与当前阶段无关的创建动作。 |

- 按钮文案使用具体动作与对象，避免仅写“开始”“去看看”；导航用链接，提交/打开表单用按钮。不能为了视觉统一增加无效按钮或更改实际操作权限。
- 文案、按钮及可访问名称均通过 `tr`；新建/接入动作继续遵守现有确认、提交与错误处理流程，不在页面加载或切换筛选时自动创建数据。
- 迁移存量页面时逐页检查容器、动作和权限，不能仅把组件名换掉就宣称规范全部落地。本节是目标约定，仍未符合的存量页面按任务范围逐步修正。
