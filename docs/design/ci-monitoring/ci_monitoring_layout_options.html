CI 监控页面布局方案

同一份配置能力的三种排版。三种方案都支持「平台内部连接」和「外部连接」的配置：内部连接编辑的是 设置 → 集成 的全局值，外部连接保存独立地址与加密凭据。静态示意，仅演示布局与信息层级。

静态示意：除方案切换和主题切换外不执行任何操作；数据为虚构示例。实际实现复用 Card / Tabs / Modal / EmptyState / tr()，深色与浅色主题均使用语义变量。
方案 首屏信息量 滚动长度 移动端 实现成本 更适合
A · 连接栏 + 链接工作区推荐 高：连接与链接同屏 短 上下堆叠，连接栏变横向区块 中 连接较多、需要边看连接状态边改链接
B · 供应商页签分区 中：一次只处理一个供应商 中 自然堆叠 低 想以最小改动收敛现有四张卡片
C · 覆盖看板 高：以 CI 类型覆盖为中心 长：类型多时继续增长 单列卡片，易读 高 以巡检覆盖和缺口发现为主，链接数量有限

方案 A · 连接栏 + 链接工作区 推荐

左栏固定承载连接和供应商切换，右侧专注 CI 链接。一次滚动即可看到「连接是否健康」和「链接配了什么」，修改内部连接时不用离开当前页。

连接状态常驻 无需上下滚动 1280px 起最佳 窄屏上下堆叠

平台内部连接的配置弹窗（三种方案共用）

内部连接不再是只读投影：点击「配置」编辑 设置 → 集成 的全局值，保存后所有引用平台连接的 CI 链接立即生效。凭据与外部连接一样只写不回显；外部连接继续使用各自的编辑弹窗。
